# pwn.navi
CTF, penetration testing, and offensive security navi cheatsheets.

Add with `navi repo add <this repo>`; browse with `navi` and filter by tag.

Tags: nmap, ffuf, curl, whatweb/nikto, dig, smb, ldap, kerberos, winrm, rdp,
bloodhound, certipy/adcs, impacket, vpn, privesc.

Variables that pick a wordlist expect seclists under `$HOME/wordlists/seclists`
and rockyou at `/usr/share/wordlists/rockyou.txt`.
